## writing style

- all prose is lowercase: site copy, readme, commit messages.
- no emojis anywhere on the site.
- README.md stays exactly one line: "my portfolio: alicedsal.github.io. built with next.js (static export), deployed to github pages with github actions." never add instructions or other sections to it.
- no resume button or resume pdf on the site: alice shares her resume only on applications and on request.
